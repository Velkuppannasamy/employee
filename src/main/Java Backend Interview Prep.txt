Expected Answer: You need to prevent race conditions and ensure data consistency through proper concurrency control. 
Here is how you can handle it:

Optimistic Locking (Recommended in High-Concurrency Scenarios)

- Use a version field in your Product table (using @Version in JPA).
- When two users try to buy the last item, only one update will succeed.
- The second update will fail with an OptimisticLockException, which you can catch and show a message like "Item is no longer available."
